# Garima Singh · Product design portfolio

Plain HTML, CSS and JavaScript. No build step: Vercel serves the files as they are.

- `index.html`, `work.html`, `about.html`, `contact.html`: the main pages
- One `.html` file per project (e.g. `transforim.html`). Their content lives in `cases.js`; the layout in `case.js` and `case.css`
- `data.js`: the project list, colours and the After work fun facts
- `work/<project>/`: each project's photos and videos

To preview on your computer: open `index.html` in a browser.
